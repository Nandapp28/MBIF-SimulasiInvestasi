# 📈 Stock Rising

![Stock Rising Banner](https://lh3.googleusercontent.com/d/1TdeCajLuiRkicxWqcOnQpfVOQdq1DibE=w1200)

**Stock Rising** is a digital board game designed to educate players on the fundamental concepts of stock investment in a fun, interactive, and risk-free environment. Originally developed as a physical board game, it has been transformed into a multiplayer Android game to reach a broader audience and improve financial literacy.

## 🚀 Download & Play

Stock Rising is officially available on the Google Play Store! You don't need to build it from source to play.

👉 **[Download Stock Rising on Google Play](https://play.google.com/store/apps/details?id=com.Polibatam.StockRising)**

## ✨ Key Features

- **Multiplayer Simulation:** Supports 2-5 players in an online environment using Client-Hosted Listen Server architecture.
- **Turn-Based Gameplay:** Experience realistic market cycles including Bidding, Action, Sell, Rumor, and Resolution phases.
- **Dynamic Market Events:** Influence stock prices using rumor cards or adapt to shifting sector performances and dividends.
- **Avatar & Border Shop:** Customize your profile by purchasing avatars and borders using "Finpoin" (virtual currency).
- **Social Features:** A complete friend system allowing users to search, add, accept, or ignore friend requests.

## 🛠️ Tech Stack

- **Game Engine:** Unity (C#)
- **Multiplayer Networking:** Photon Unity Networking (PUN 2)
- **Database & Authentication:** Firebase Realtime Database & Anonymous Login
- **UI/UX & 3D Modeling:** Figma, Blender
